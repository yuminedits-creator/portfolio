# Yumin Chang portfolio

Static portfolio with six projects, About Me, contact form, and social links.

## Cloudflare Pages

- Production branch: `main`
- Framework: None
- Build command: `exit 0`
- Build output directory: `dist`

Five films use YouTube embeds. The UBC Biztech film is a small local MP4 included in the repository. Original large video files are ignored and are not required for deployment.

## Contact form

The form uses FormSubmit to deliver enquiries to yuminedits@gmail.com. Complete the one-time inbox activation and test delivery on the live site before considering email delivery verified.

## Editing

Create a working branch for future changes, review Cloudflare's preview deployment, then merge into `main` to update the live website.
